# React 不可变更新范式

> 基于 `06-context` 中的状态更新场景整理。

---

## 一、什么是不可变更新？

不可变更新（Immutable Update）是指：**不直接修改原来的 state，而是创建一个新的对象/数组，把修改后的值放进去。**

React 通过比较==引用==来判断 state 是否变化。如果直接修改原对象，引用没变，React 就认为 state 没变化，不会重新渲染。

---

## 二、对象更新的范式

### 基本写法

```jsx
const [user, setUser] = useState({ name: 'Alice', role: 'admin' });

// 修改 name，保留 role
setUser(prev => ({ ...prev, name: 'Bob' }));
```

> 新起一个 + 后面的覆盖前面的

### 执行过程

```jsx
setUser(prev => ({ ...prev, name: 'Bob' }));

// prev = { name: 'Alice', role: 'admin' }
// { ...prev, name: 'Bob' } = { name: 'Alice', role: 'admin', name: 'Bob' }
// 后面的 name 覆盖前面的 name
// 最终结果：{ name: 'Bob', role: 'admin' }
```

---

## 三、通用字段更新函数

如果字段名是变量，用计算属性名 `[field]`：

```jsx
const updateField = (field, value) => {
  setUser(prev => ({ ...prev, [field]: value }));
};

updateField('name', 'Bob');     // { name: 'Bob', role: 'admin' }
updateField('role', 'user');    // { name: 'Bob', role: 'user' }
```

---

## 四、数组更新的范式

数组也是引用类型，同样不能直接修改，==要返回新数组==。

### 添加元素

```jsx
const [items, setItems] = useState([1, 2, 3]);

setItems(prev => [...prev, 4]); // [1, 2, 3, 4]
```

### 删除元素   | filter 返回新数组

```jsx
setItems(prev => prev.filter(item => item !== 2)); // [1, 3]
```

### 修改某个元素  | map 返回新数组

```jsx
setItems(prev => prev.map((item, index) =>
  index === 1 ? item * 10 : item
)); // [1, 20, 3]
```

### 在指定位置插入 |  拼接，他妈的还能这么写？？？

```jsx
setItems(prev => [...prev.slice(0, 2), 99, ...prev.slice(2)]);
// [1, 2, 99, 3, 4]
```

## 五、为什么不能直接修改？

### ❌ 错误写法

```jsx
user.name = 'Bob';  // 直接修改原对象
setUser(user);      // 引用没变
```

React 比较：

```js
prevUser === user // true，引用相同
```

React 认为 state 没变，**不会重新渲染**。

### ✅ 正确写法

```jsx
setUser(prev => ({ ...prev, name: 'Bob' }));
```

新对象的引用和旧对象不同，React 检测到变化，触发重新渲染。

## 六、嵌套对象怎么更新？

如果 state 是嵌套对象，要一层一层展开：

```jsx
const [user, setUser] = useState({
  name: 'Alice',
  profile: {
    age: 25,
    city: 'Beijing',
  },
});

// 修改 profile.age
setUser(prev => ({
  ...prev,
  profile: {
    ...prev.profile,
    age: 26,
  },
}));
```

结果：

```js
{
  name: 'Alice',
  profile: {
    age: 26,
    city: 'Beijing',
  },
}
```

嵌套层级太深时，可以考虑用 `immer` 等库简化。

## 七、常见场景速查表

| 场景 | 写法 |
|------|------|
| 对象修改一个字段 | `setObj(prev => ({ ...prev, key: value }))` |
| 对象修改多个字段 | `setObj(prev => ({ ...prev, key1: v1, key2: v2 }))` |
| 数组添加元素 | `setArr(prev => [...prev, item])` |
| 数组删除元素 | `setArr(prev => prev.filter(...))` |
| 数组修改元素 | `setArr(prev => prev.map(...))` |
| 数组插入元素 | `setArr(prev => [...prev.slice(0, i), item, ...prev.slice(i)])` |

---

## 八、一句话总结

> 不可变更新范式：**`setXxx(prev => ({ ...prev, field: newValue }))`**。先展开旧的，再覆盖新的。对象用 `...` 展开，数组用 `...` 或 `map/filter` 返回新数组。
