# 15 TypeScript

> **本章目标**：掌握 React + TypeScript 的开发模式。  
> **预计学习时间**：90 分钟

---

## 📝 核心概念

- `React.FC` 已不推荐使用，直接声明 Props 接口
- 使用 `ComponentProps<'element'>` 获取原生元素类型
- 泛型组件提高复用性

## 🧠 面试题

**Q: interface 和 type 的区别？**  
A: interface 可合并声明，适合对象类型；type 更灵活，支持联合类型、条件类型等。

---

## 📝 总结

- TypeScript 大幅提升 React 项目的可维护性
- 善用工具类型（Pick、Partial、Omit）
- 优先从业务出发定义类型，而非过度工程化
