# 14 Next.js 入门

> **本章目标**：了解 Next.js App Router 和渲染策略。  
> **预计学习时间**：90 分钟

---

## 🏗️ App Router 核心

- `page.tsx` = 路由页面
- `layout.tsx` = 共享布局
- `loading.tsx` = 加载状态
- `error.tsx` = 错误处理

## 🔄 渲染策略

| 策略 | 说明 |
|------|------|
| SSR | 每次请求服务端渲染 |
| SSG | 构建时静态生成 |
| ISR | 增量静态再生 |
| RSC | React Server Components |

---

## 📝 总结

- Next.js 是 React 的全栈框架
- App Router 是推荐的最新路由方案
- Server Components 减少客户端 JS 体积
