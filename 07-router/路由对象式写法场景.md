我设计一个**商品详情页**场景，包含：**数据预加载**、**提交评论**、**错误兜底**。

---

## 1. 路由配置（对象写法）

```jsx
// router.jsx
import { createBrowserRouter } from 'react-router-dom';
import Layout from './Layout';
import ProductDetail from './ProductDetail';
import ErrorPage from './ErrorPage';

const routes = [
  {
    path: '/',
    element: <Layout />,
    children: [
      {
        path: 'products/:id',
        element: <ProductDetail />,
        
        // ⭐ 页面渲染前，自动调用 loader 加载数据
        loader: async ({ params }) => {
          const res = await fetch(`/api/products/${params.id}`);
          if (!res.ok) throw new Error('商品加载失败');
          return res.json();  // 返回的数据会被组件用到
        },
        
        // ⭐ 处理该页面下的表单提交
        action: async ({ request, params }) => {
          const formData = await request.formData();
          const comment = formData.get('comment');
          
          const res = await fetch(`/api/products/${params.id}/reviews`, {
            method: 'POST',
            body: JSON.stringify({ comment }),
            headers: { 'Content-Type': 'application/json' },
          });
          
          if (!res.ok) throw new Error('评论提交失败');
          return { success: true };  // 返回结果会被组件用到
        },
        
        // ⭐ loader 或 action 抛错时，显示这个组件，而不是白屏
        errorElement: <ErrorPage />,
      },
    ],
  },
];

export const router = createBrowserRouter(routes);
```

## 3. 组件里怎么拿数据？

```jsx
// ProductDetail.jsx
import { 
  useLoaderData,    // 获取 loader 返回的数据
  useActionData,    // 获取 action 返回的结果
  useParams,
  Form              // 特殊的表单组件，会自动走 action
} from 'react-router-dom';

function ProductDetail() {
    
  const product = useLoaderData();   // ← 直接拿到 loader 返回的商品数据
  const actionResult = useActionData(); // ← 提交表单后拿到 action 的返回值
    
  const { id } = useParams();

  return (
    <div className="card">
      <h2>📦 {product.name}</h2>
      <p>¥{product.price}</p>
      <p>{product.desc}</p>

      <hr />

      {/* ⭐ Form 组件：提交后会自动调用上面的 action，不刷新页面 */}
      <Form method="post">
        <textarea name="comment" placeholder="写评论..." required />
        <button type="submit">提交评论</button>
        
        {/* 显示提交结果 */}
        {actionResult?.success && <span>✅ 评论已提交</span>}
      </Form>
    </div>
  );
}

export default ProductDetail;
```

## 4. 错误兜底页面

```jsx
// ErrorPage.jsx
import { useRouteError } from 'react-router-dom';

function ErrorPage() {
    
  const error = useRouteError();  // ← 拿到 loader/action 抛出的错误对象
    
  
  return (
    <div style={{ color: 'red', padding: '2rem' }}>
      <h1>😵 出错了</h1>
      <p>{error.message}</p>       {/* 显示："商品加载失败" 或 "评论提交失败" */}
      <button onClick={() => window.location.reload()}>刷新试试</button>
    </div>
  );
}

export default ErrorPage;
```

## 5. 为什么对象写法更方便？看对比

| 功能           | 对象写法 ✅                                       | JSX 写法 ❌（或不方便）                         |
| -------------- | ------------------------------------------------ | ---------------------------------------------- |
| **数据预加载** | `loader` 直接挂在路由对象上                      | 得在组件里写 `useEffect + fetch`，每个页面重复 |
| **表单提交**   | `action` 直接挂在路由对象上，`Form` 组件自动对接 | 得自己写 `onSubmit + fetch + 状态管理`         |
| **错误边界**   | `errorElement` 直接挂在路由对象上                | 得自己包 `try/catch` 或写 React 错误边界类组件 |
| **并行加载**   | 多个 `loader` 自动并行执行                       | 得自己控制 Promise.all                         |

---

## 一句话总结场景

> **`loader`** = 进页面前自动拉数据（不用 `useEffect`）  
> **`action`** = 提交表单时自动处理（不用手写 `fetch` + 状态）  
> **`errorElement`** = 请求出错时自动显示错误页（不会白屏）  

这三个特性**只能**（或最方便）通过对象写法使用，JSX 写法做不到这么干净。
